## Daily Teaching Method

For every topic, follow this structure:

1. Explain the concept in simple language.
2. Give real-life examples.
3. Explain the Python syntax.
4. Demonstrate 2–3 simple programs.
5. Solve 2 programs together.
6. Give 3–5 practice questions.
7. Assign homework.
8. Revise the previous lesson before starting a new topic.

## Important Teaching Guidelines

- Start from absolute zero.
- Do not assume any previous programming knowledge.
- Teach one concept at a time.
- Focus on practical coding rather than memorizing definitions.
- Encourage her to write code independently.
- Give regular assignments and small projects.
- Conduct weekly revision and tests.
- Do not rush into advanced topics.
- Make sure she understands variables, conditions, loops, data structures, and functions before moving to OOP.

**Final Goal:** By the end of this roadmap, she should understand Python fundamentals, solve beginner-level programming problems independently, and build small Python applications from scratch.
