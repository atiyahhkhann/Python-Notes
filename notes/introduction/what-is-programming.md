# What is programming?

Programming is giving instructions to a computer so it can do a task for you.

- A computer is very powerful, but it can't think on its own. It only does exactly what it is told, so we have to tell it what to do, step by step. That's what programming is.

### Real-Life Example

## Making Tea ☕
- Imagine you're explaining to a friend who has never made tea:
    1. Boil water
    2. Add tea leaves
    3. Add milk and sugar
    4. Pour into a cup

- If you skip a step or put the steps in the wrong order, the tea turns out wrong. Computers work the same way. A list of clear steps like this is called an algorithm, and writing it in a language the computer understands is programming.

## What is a Program?

- A program is a set of instructions written for a computer.
- Everything you use is a program: WhatsApp, Instagram, YouTube, games, and even the calculator on your phone.

## What is a Programming Language?

- Computers don't understand English or Hindi. They only understand 0s and 1s (called machine language). Writing in 0s and 1s is extremely hard for humans, so we use programming languages, which are easier for us to read and write. <b>Examples</b>: Python, Java, C++, JavaScript
- A programming language is like a translator between you and the computer:-

`You (Python code) → Computer translates it → Computer does the task`


## Difference between compiler and interpreter
- Computers only understand 0s and 1s, so the code we write must be translated, and this is done by a compiler or an interpreter.
- A <b>compiler</b> translates the whole program at once into machine language and then runs it, like translating an entire speech on paper before handing it over.
- An <b>interpreter</b> translates and runs the program line by line, like a live translator who translates each sentence as the speaker talks, and it stops right away if it finds a mistake.
- <b>Python</b> uses an <b>interpreter</b>, which is why we can run code one line at a time and see errors immediately, making it great for beginners.
